# MobileNet on CIFAR-10

## Objective
Build a lightweight image classification system using MobileNetV2 on CIFAR-10 dataset.

## Technologies Used
- Python
- TensorFlow/Keras
- Google Colab

## Dataset
CIFAR-10 dataset containing 10 image classes.

## Model
MobileNetV2 using transfer learning.

## Final Accuracy
Achieved approximately 86% test accuracy.

## Features
- Lightweight CNN model
- Image classification
- Transfer learning
- Random image prediction demo
